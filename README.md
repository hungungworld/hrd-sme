# 중소기업 HRD 교육 현황

HRD를 혼자 맡은 중소 무역회사 담당자가 **이번 주에 무엇을 할지** 정하는 대시보드입니다.
법정교육 마감, 고용보험 환급, 교육 사각지대, 무역 직무 역량을 한 화면에서 봅니다.

> 회사명, 인원, 금액 등 모든 수치는 포트폴리오용으로 만든 **가상 데이터**입니다.

## 화면 구성

가상 무역회사, 임직원 210명, 2026년 1월 1일 ~ 10월 30일 누적 기준입니다.
화면 위쪽 **부서 필터**로 모든 탭을 부서별로 볼 수 있습니다. 단, 환급 탭은 회사 단위로 신청하므로 전사 기준입니다.

| 탭 | 답하는 질문 | 핵심 기준 |
|---|---|---|
| 운영 현황 | 지금 교육이 계획대로 가고 있나? | 법정의무교육 이수율 90% 미만이면 빨강 |
| 법정교육 마감 대응 | 12월 31일까지 누구에게 안내해야 하나? | 남은 날(D-day), 과정별·부서별 미이수 인원, 이번 주 안내 대상 |
| 교육 사각지대 | 평균에 가려진 사람이 있나? | 법정의무교육을 빼고 연간 8시간 미만인 직원 |
| 예산·환급 | 고용보험 환급을 놓치고 있지 않나? | 과정별 환급 진행 상태, 사전 인정 없이 진행해 못 받는 금액 |
| 직무 역량 지도 | 어느 부서의 어떤 무역 역량이 부족한가? | 요구 수준 − 보유 수준이 1.0 이상이면 빨강 |

**환급 상태는 다섯 가지입니다.** 지급 완료 · 지원금 신청 · 수료 확인 중 · 환급 없음 · 대상 아님.
사전에 훈련과정 인정을 받지 않은 사내 과정은 **환급 없음**이며, 다음 차수부터 인정을 받으면 아낄 수 있는 금액을 보여 줍니다.

## 데이터

| 파일 (`data/`) | 내용 |
|---|---|
| `depts.csv` | 부서와 인원 |
| `monthly.csv` | 부서별 월간 교육시간·교육비 |

| `competencies.csv`, `comp_levels.csv` | 무역 직무 역량 정의와 부서별 요구·보유 수준 |

## 디자인 규칙

새 화면을 만들거나 고칠 때 아래 규칙을 모두 지킵니다.

### 1. 정렬

- **덩어리 하나에 정렬 기준선은 하나**입니다. 가운데면 전부 가운데, 왼쪽이면 전부 왼쪽입니다.
- 대시보드는 기본이 **왼쪽 정렬**입니다.
- 가운데 정렬은 **3줄 이하의 짧은 순간**에만 씁니다. 예: 데이터 없음, 짧은 알림, 결과 팝업.
- 박스를 가운데에 두고 안의 글은 왼쪽 정렬해도 됩니다. 박스 테두리가 새 기준선이 됩니다.

### 2. 줄바꿈

**단어 중간에서는 절대 끊지 않습니다.** 모든 페이지의 최상위 요소에 아래 설정을 넣습니다.

```css
word-break: keep-all;      /* 띄어쓰기 단위로만 줄바꿈 */
overflow-wrap: anywhere;   /* 칸보다 긴 단어만 예외로 자름 */
```

**의미 단위는 "끊을 곳"이 아니라 "안 끊길 곳"을 묶어서 지킵니다.**

- 안 끊길 묶음:
  - 숫자 + 단위 + 조사 (`292명이`, `37.3%를`)
  - 과정명, 조직명, 역량명
  - 기간 (`1~10월`), 날짜 (`12월 31일`)
- 묶음은 `<span class="nb">`로 감싸고 `display: inline-block; max-width: 100%`를 줍니다.
  - 줄이 넘치면 묶음 통째로 다음 줄로 갑니다.
  - 칸보다 긴 묶음만 안에서 감깁니다. 화면 밖으로 넘치지 않습니다.

```html
<span class="nb">부족분의 <b>37.3</b>%를</span> <span class="nb">채울 수 있습니다.</span>
```

**직접 줄을 나누는 곳은 정해져 있습니다.**

| 글의 종류 | 줄 나누기 | 한 줄 최대 길이 |
|---|---|---|
| 화면 맨 위 결론 문장 | 문장마다 새 줄로 시작 (`display: block`) | 약 40자 |
| 차트·표 설명 | 직접 끊지 않음, 자연스럽게 감김 | 약 45자 |
| 위젯·카드 안 글 | 직접 끊지 않음 | 약 24자 |
| 제목 | `text-wrap: balance` | — |
| 설명 문단 | `text-wrap: pretty` | — |

- `balance`: 두 줄 길이를 고르게 맞춰, 제목 끝에 한 단어만 남지 않게 합니다.
- `pretty`: 문단 마지막 줄에 한두 단어만 남지 않게 합니다.
- 두 설정은 길이만 봅니다. 뜻은 모르기 때문에, 의미 단위는 위의 묶기로 지킵니다.
- `text-wrap-style`만 바꾸고 싶을 때 `text-wrap` 단축 속성을 쓰면 `white-space: nowrap`이 풀릴 수 있으니 주의합니다.

### 3. 글자는 잘리지 않습니다

- `text-overflow: ellipsis`("…")를 쓰지 않습니다. 넘치는 글은 다음 줄로 넘깁니다.
- 배지가 제목 옆에 안 들어가면 배지가 다음 줄로 내려갑니다 (`flex-wrap: wrap`).
  - 제목이 한 글자씩 세로로 쌓이게 두지 않습니다.
  - 첫 줄만 들여쓴 것처럼 보이게 두지도 않습니다.

### 4. 숫자

- 숫자와 단위는 붙여 쓰고, 단위는 숫자보다 작게 씁니다 (`292명`, `87.3%`).
- 같은 지표는 소수 자릿수를 똑같이 맞춥니다.
- 표 안의 숫자는 오른쪽 정렬하고 `font-variant-numeric: tabular-nums`를 씁니다.
- 숫자는 HTML에 직접 쓰지 않습니다. 모두 `data/`의 CSV에서 계산해서 채웁니다.

### 5. 색

| 표현 | 뜻 | 규칙 |
|---|---|---|
| 빨강 | 기준 미달, 먼저 조치 | 한 화면에 빨간 강조는 3개까지 |
| 점선 | 목표 또는 평균 | 기준선에만 씀 |
| 회색 | 비교 대상 (대기 조직, 기타) | |
| 회색 띠 | 교육 기간 | 시계열 차트에서만 |
| 파랑 | 기본 데이터 색 | |

색만으로 뜻을 전하지 않습니다. 빨간 막대 옆에는 숫자를 함께 둡니다.

### 6. 설명의 양

- 화면마다 **결론 1문장** (2줄 이내)만 둡니다.
- 차트·표마다 **설명은 1줄**까지만 둡니다.
- 둘러보기 투어, 용어 설명 팝업, 탭별 안내 상자는 **쓰지 않습니다.**
  - 실제로 넣어 봤는데 화면이 복잡해지고 읽기 어려워졌습니다.
  - 무엇이 중요한지는 설명이 아니라 **빨간 표시와 "먼저 볼 곳" 번호**로 보여 줍니다.
- 강조는 따옴표 대신 **굵게** 합니다.

### 7. 간격

- 모든 간격은 **8의 배수**입니다. 4px는 아주 작은 틈에만 씁니다.

| 사이 | 간격 |
|---|---|
| 제목 → 본문 | 8px |
| 카드 안 요소끼리 | 8~12px |
| 카드 → 카드 | 12~20px |
| 화면의 큰 덩어리 → 덩어리 | 32px |

- **제목과 본문 사이는 항상 본문과 다음 덩어리 사이보다 좁게** 둡니다. 그래야 "이 제목의 글"로 묶여 보입니다.
- 여러 줄짜리 글 옆의 아이콘·배지는 첫 줄 높이에 맞춥니다.

### 8. 글꼴

| 역할 | 글꼴 |
|---|---|
| 본문, 표, 버튼 | Pretendard |
| 큰 숫자, 화면 제목 | Noto Serif KR |

### 9. 반응형

- 고정 너비를 쓰지 않습니다. 차트는 담긴 칸의 너비에 맞춰 다시 그립니다.
- 위젯 보드는 너비에 따라 4칸 → 2칸 → 1칸으로 줄어듭니다 (880px, 520px 기준).
- 좁은 화면에서는 표의 보조 열을 숨깁니다.
- 휴대폰 너비(약 375px)에서도 가로 스크롤 없이 읽혀야 합니다.

## 폴더 구조

```
hrd-sme/
├─ index.html          배포되는 대시보드 (build.py가 만듦)
├─ data/*.csv          대시보드 데이터 8종
├─ assets/
│  ├─ base.css         색·글자·간격 값 (라이트·다크)
│  └─ dash-lite.js     CSV를 읽어 숫자와 차트를 그리는 실행 코드
├─ _source/
│  ├─ dashboard.html   화면 원본
│  ├─ build.py         원본 → index.html
│  └─ scripts/         가상 데이터 생성 스크립트
├─ .vercelignore
└─ README.md
```

- `_source/`는 배포에서 빠집니다 (`.vercelignore`).
- 차트는 [d3 v7](https://d3js.org)로 직접 그립니다. 빌드 도구 없이 정적 파일만으로 동작합니다.

## 고치는 법

| 고칠 것 | 고칠 파일 | 그다음 |
|---|---|---|
| 숫자 (데이터) | `data/*.csv` | 바로 반영 |
| 화면 (문구, 차트, 계산) | `_source/dashboard.html` | `python _source/build.py` 실행 |
| 색, 글꼴, 간격 값 | `assets/base.css` | 바로 반영 |

`index.html`은 `build.py`가 만드는 파일이니 직접 고치지 않습니다.

## 로컬에서 보기

```bash
python -m http.server 5317
```

브라우저에서 `http://localhost:5317`을 엽니다. CSV를 불러오기 때문에 파일을 더블클릭해서 열면 데이터가 뜨지 않습니다.

## 배포

이 폴더 하나가 Vercel 프로젝트 하나입니다. 폴더 안에서 실행합니다.

```bash
npx vercel deploy --prod
```
